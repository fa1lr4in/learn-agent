  version: "0.1.0"

只执行当前用户要求的核对范围。本文的源码路径相对 workspace。

1. 用户已指定文件时直接核对；未指定时先浏览项目，找到入口和验收文件。
2. 若本次提供 plugin_python_check_inspect_python，先使用它检查入口和测试文件的结构。它只做静态解析，结果不能证明代码运行成功。未提供时使用现有读取工具，不虚构插件能力。
3. 阅读必要源码；用户要求实际验收时，使用现有运行工具执行项目测试和入口。工具调用仍需遵守本次权限和预算。
4. 根据真实结果，用“源码结构”“验收结果”“未完成事项”三项简短报告。分别说明 stdout、stderr 和退出码；静态检查或模型推测不能代替验收通过。
