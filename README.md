# learn-agent

一个正在逐步开发的本地编程 Agent，使用 Python 实现核心能力。

## 已实现功能

- 调用 DeepSeek 官方 API，发送问题并查看完整响应。
- 单独展示助手回答、停止原因和 token 用量，提示输出被截断的情况。
- 通过 `--chat` 连续对话，每次请求携带本次会话的历史，输入 `/exit` 退出。
- 输入 `/clear` 清空当前对话历史，保留系统指令；清空操作本身不调用模型。
- 预览请求内容，无需密钥或网络调用。
- 从环境变量或终端读取 API Key，通过环境变量选择模型。
- 根据模型的工具请求，经用户确认后读取指定练习文件，再将结果交回模型。
- 文件工具演示支持从命令行传入问题，模型可直接回答或提出工具请求。
- 支持 Agent 循环：每轮执行一个工具请求，携带结果继续请求模型，直到模型正常回答。
- 文件工具返回 JSON：`ok: true` 携带文件内容；读取失败时返回 `ok: false` 和错误类型，让模型据此调整后续操作。
- 每次运行最多请求模型 5 次；用户拒绝、非法工具请求或模型异常结束时停止。
- 检查工具名称、参数和允许读取的文件；拒绝确认时停止执行。

模型调用、多轮对话、清空历史和连续读取两份文件的 Agent 循环已由使用者真实运行成功；工具读取错误反馈与后续调整已通过离线测试，真实调用待验证。

## 运行

需要 Python 3.11 或更新版本，无第三方依赖。

```powershell
# 预览请求
python chat.py --preview "你好"

# 调用模型；按本地终端提示输入密钥
python chat.py "请用一句话介绍你自己。"

# 开始多轮对话，首条消息作为命令参数传入
python chat.py --chat "我的项目叫小灯。"

# 预览文件工具请求，不联网或读取文件
python tool_call.py --preview

# 运行 Agent 循环；默认根据项目文件中的线索继续读取任务文件
python tool_call.py

# 也可以传入自己的问题
python tool_call.py "请读取 project.txt，告诉我项目使用什么语言。"
```

可以通过 `DEEPSEEK_API_KEY` 环境变量提供密钥，通过 `DEEPSEEK_MODEL` 指定模型；默认模型为 `deepseek-flash`。程序不会将密钥保存到文件。

多轮历史保存在当前进程的内存中，每次请求会重新发送该历史。在 `你>` 提示后输入 `/clear`，后续请求只保留系统指令和清空之后的对话。退出程序后历史不保留。`--preview` 仍然只展示首个请求，不进入交互或调用模型。

文件工具只允许读取 `workspace/project.txt` 和 `workspace/next_step.txt`。第一次请求提供工具名称、用途和参数格式，不包含文件正文。模型返回 `tool_calls` 后，程序检查工具名称和参数；每次输入 `y` 后才读取对应文件，再用 `role: tool` 和对应的 `tool_call_id` 将内容交回模型。其他输入会停止本次任务。

工具结果统一编码成 JSON 字符串放入 `tool` 消息。成功结果包含 `ok`、`path` 和 `content`；文件不存在、无读取权限或文本解码失败时，返回 `ok: false`、`path` 和 `error`，循环继续由模型决定下一步。非法工具或参数仍会停止，用户拒绝仍会停止；API 请求失败不作为文件工具错误处理。

后续请求继续使用 `tool_choice: auto`，模型可以再次请求工具，也可以直接回答。当前每轮只处理一个工具请求，同一回复包含多个工具请求时会停止并提示。`finish_reason` 为 `stop` 时显示最终回答；`length` 等异常结束不会执行本轮工具。最多请求模型 5 次，如果第 5 次仍要求工具，则停止且不执行该次工具，提示任务未完成。

## 验证

```powershell
python -m unittest discover -s tests -v
```

测试模拟服务响应，不调用真实 API，检查多轮消息历史、清空历史、退出与预览行为，以及连续工具结果对应关系、读取错误反馈、失败后改读其他文件、调用次数上限、直接回答、拒绝执行、异常结束和非法请求。
